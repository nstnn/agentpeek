# Session detail

Wide selection shows the session header and recent exchange. Both panes are replaceable. Ordinary selection opens in the active pane, remembered through browsing; rows support explicit context-menu placement and drag previews. Split reading and list visibility follow the width left by Views; see navigation-visibility.md. Show Sessions and Hide Sessions preserve both details. A loaded active visible detail marks its current reply/error read when the native window is focused.

## Sub-features

- `detail-split`: left/right context placement, session-title headers, active-pane row activation, close and independent local state.
- `detail-drag`: row drag opening/replacement previews, valid drop commit, Escape/outside cancellation and stale-source rejection.
- `detail-compact-split`: replacement browse/return, compact keyboard pane selector, hidden-pane deferral and focus/scroll preservation through resize.
- `detail-messages`: immediate header, last 20 messages, Latest exchange, times and tool summaries.
- `detail-tool-calls`: collapsed Codex group/call disclosures, recorded input/time, literal nested names with execution uncertainty, missing/empty/truncated input, capped groups and live-state retention. Claude calls lead with a summary line, show tool name and status (Failed, Interrupted, Running/Waiting, No result), a failed call's short error, Edit diffs and Open Claude truncation notices.
- `detail-skill-content`: explicit Codex references and recognized Claude slash skills become read-only expandable cards; follow skill-content.md for source labels, retry and isolation.
- `detail-loading`: loading, partial, empty, failed and Try Again states.
- `detail-markdown`: GFM, literal HTML, image alt text and safe web-link dispatch.
- `detail-title`: single-pane two-line initial title with the full accessible heading and width-aware Show Full Title / Show Less Title.
- `detail-long-message`: reversible 6,000-character preview and expansion up to 200,000, truthful cap notices, stable focus and reachable scroll controls.
- `detail-actions`: Open Codex or Open Claude, Mark Read and Pin/Unpin. Copy Session ID remains in the Session menu and row context menu (Option-Command-C), not the detail header.
- `detail-read`: only the active visible successfully loaded detail, after successful current target synchronization and native focus, can acknowledge a matching reply cursor; viewing never clears waiting.
- `detail-navigation`: narrow click/Return, Back, Escape and Session > Back restore row/focus.
- `detail-live`: refresh preserves focus/scroll and discards stale requests.
- `detail-focus`: keyboard focus in Recent messages uses a short header-edge cue instead of a rectangle around the transcript; buttons and links retain their own focus indicators.
- `detail-source-recovery`: missing selections show Unavailable with frozen Last seen in AgentPeek and use bounded source reload instead of transcript retry.

## How to get to it (user POV)

- Select a row in any view; wide detail appears immediately.
- Narrow: arrows select; click or Return opens detail.
- Use header actions, Show Full Title / Show Less Title, Show More / Collapse Message, Back to Message Start, Try Again or Session/context menus.
- Expand a Codex or Claude tool-call summary, then any individual call to read its recorded input (and a failed Claude call's error). Enter/Space on the focused summary toggles it.
- Return with the icon named Show Sessions in the reading header, Escape or Session > Back (Command-[).
- Use the independent Show Sessions / Hide Sessions control to browse or resume reading. When only one detail fits, use title radios (arrows, Home/End). Each visible split toolbar has its pane-specific close control; browsing retains Close Right Pane.

## Gotchas

- Hidden narrow detail never loads or marks read; width alone never enables Back.
- Automatic read carries the loaded cursor; main rejects a newer reply.
- Terminal errors remain Error · Read in row and detail after acknowledgement until a newer turn starts; waiting semantics remain unchanged.
- Last seen in AgentPeek is snapshot membership observation, not proof of a fresh filesystem read. Missing membership freezes that time; unknown provenance remains Unknown.
- Conversation/error text is on-demand memory only, never snapshot/state data. Evidence is synthetic only.
- Loading/request races have component tests; fast real reads may finish before a screenshot.
- Title overflow and sticky-control geometry require a real renderer; mocked component dimensions cannot prove layout. Expanded text still obeys 200,000 characters and never loads full history.
- Test Collapse immediately after rapid PageDown, while keyboard scrolling is still moving: the preview must return to its message start after that motion settles. A subsequent wheel/key/pointer action must cancel that return instead of pulling the user's new scroll backward.
- DOM/AX labels do not establish VoiceOver speech, physical resizing, external activation or packaged behavior.
