# Sessions list

The window opens in Active with tool health, attention groups and live counts. Pinned and All Sessions share the tool filter. Rows show titles, folders, labeled states, relative times and pins. Selection stays in its group and slot until another row or filter is chosen; updates do not take focus or move the visible selected row. Wide selection shows detail; below 1000 content pixels, click or Return opens detail with Back (see session-detail.md).

## Sub-features

- `list-projects` defaults to collapsible working-folder groups; Group by switches to Status. See [Project grouping](./project-grouping.md).

- `list-views` switches Active, Pinned and All Sessions through sidebar or View menu.
- `list-filter` filters every view by All, Codex or Claude Code, with live per-view counts.
- `list-empty-scope` distinguishes no sessions in a view from sessions hidden by its tool filter, with clear-filter or browse actions and restored keyboard focus.
- `list-attention-count` explains Active's unfiltered attention badge in its tooltip and accessible name, including zero while sessions run.
- `list-groups` orders Waiting for you, Errors, New replies, Running and Unknown, with text status labels.
- `list-second-marker` names naturally listed Right sessions; one list cursor follows the active pane without changing counts.
- `list-placement` supports row drag/cancel and explicit left/right context placement; ordinary clicks use the active or remembered pane.
- `list-selection` starts unselected, supports arrows/Home/End, keeps selected rows through updates and supplies the Session menu target.
- `list-focus` uses the selected row highlight and a short header-edge cue for keyboard focus, including before a row is selected, without outlining the whole list.
- `list-retained-status` labels acknowledged errors Error · Read, explains retained positions and names current/outstanding group membership.
- `list-source-reload` offers an inline Reload Sessions action in no-access warnings without hiding a healthy source.
- `list-context` opens the native row menu by right-click or Shift+F10 and shows a gray row until dismissal, without selecting that row or replacing the displayed detail.
- `list-health` shows both sources, first-launch copy, fixture/local-state warnings and filtered empty/error states.
- `list-time` refreshes relative times once a minute without re-sorting or moving focus.

## How to get to it (user POV)

- Open AgentPeek and select Active, Pinned or All Sessions in the sidebar or View menu (⌘1–⌘3).
- Choose a tool above the list. Tab enters the sidebar, then Group by, then tool filter, then the first-launch dismiss button if visible, then list; arrow keys choose within each composite control.
- Click a row or use Up/Down/Home/End in the list. Choose actions in the Session menu.
- Right-click/Control-click a row, or select it and press Shift+F10, for its context menu.
- Close the first-launch strip with its labeled × button. View > Reload Sessions retries source reads.
- In a filtered empty view, choose Show All Pinned, Show All Active or Show All Sessions to clear only the tool filter. With no pins in either tool, Browse All Sessions changes the view and keeps the tool filter.
- Hover Active to read its attention explanation; keyboard/accessibility users receive the attention count in its name even when the visible badge is absent at zero.

## Gotchas

- Counts explicitly describe outstanding/current membership even while a selected row is retained; an old group may show 0 outstanding/current until selection changes. Kept here while selected explains the retained row.
- Empty-state recovery uses current-view membership before the tool filter, not the total snapshot session count. Pins or idle sessions elsewhere do not imply hidden Active rows. Clear-filter actions keep the view; browse actions keep the tool filter. Both move focus to the selected tool radio when their button disappears.
- Active counts attention across both tools, not every Active row. Pinned/All sidebar numbers count sessions; tool-filter numbers count the current view before filtering, and the header summary counts the current filtered view.
- When earlier content grows or shrinks, temporary blank space and the scroll offset keep the selected row at the same visible position. Selecting another row releases that space; user scrolling establishes a new anchor.
- Switching view or tool filter clears the list cursor and restores normal grouping; split retains both detail selections. A disappeared selected session remains visible; native actions are disabled because the main process rechecks the current source.
- Menu accelerators need native menu dispatch: `key Meta+1` does not reach the View menu through CDP.
- Native popup pixels/actions are outside this helper's reach. A page screenshot and a pending popup promise prove only the row's entry/highlight, not native menu rendering.
- Live updates have aria-live off. AX labels and keyboard behavior can be checked here; actual VoiceOver speech remains a separate platform check.
- See session-detail.md for transcript loading, focused read-on-view and narrow activation/Back.
- In compact split browsing, arrows change only the list cursor without loading hidden content; Enter/click replaces the remembered active pane. Explicit context/drop placement chooses Left or Right. Show Sessions restores this shared list, views, filters and source health; Return to Sessions resumes the remembered pane. Resizing while browsing keeps details hidden, including at roomy widths.
